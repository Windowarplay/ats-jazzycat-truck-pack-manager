## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Pack Browser** | Browse all Jazzycat truck and trailer packs with previews |
| **Version Tracker** | Track installed Jazzycat pack versions and available updates |
| **Activation Manager** | Enable or disable individual packs per ATS profile |
| **Compatibility Check** | Check pack compatibility with your current ATS version |
